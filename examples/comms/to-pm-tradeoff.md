# Example: message to PM (tradeoff)

**Subject:** Onboarding polish — scope options for next sprint

Context: we can ship onboarding **functional** this sprint, or slip **one week** to include the **empty-state illustrations** and **micro-motions** from the latest design.

**Recommendation:** Ship functional now; schedule illustrations next sprint so QA isn’t compressed on the critical path.

**Tradeoff:** First week users see simpler empty states; no blocker to completion or compliance.

If you prefer holding for full polish, we should cut a downstream ticket of equal size — I suggest deferring the **secondary tooltip tour** (lower impact than empty states).
